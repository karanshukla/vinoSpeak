## [0.2.0] - 2026-10-23

### 🚀 Features

- Read a text file aloud with `--file` (`--file -` reads stdin). Markdown is cleaned up for speech: headings, list items and table rows become sentences, links keep their text, URLs are said as their host, and code blocks are skipped
- `--print-text` shows what would be spoken without loading the model
- `--audio-device` picks the output, passed to pw-play, paplay or aplay
- A vinoSpeak window (`gui/`, proof of concept): find a file with vinoSearch, preview the text it would speak, and read it aloud with a chosen voice, speed and output. It lists vinoSearch's recently changed files before a search, reads documents through vinoSearch's text extraction, and names Kokoro's voices under their accent. `install.sh` adds it to the app menu with the vinoSpeak icon

### 🐛 Bug Fixes

- The window centres its reading column when wide, and leaves images out of search results

### 🧪 Testing

- The window is driven headless with egui_kittest in CI, and is readable by a screen reader (accesskit)

## [0.1.0] - 2026-10-21

First release on PyPI. Kokoro-82M INT8 on the NPU through OpenVINO GenAI 2026.4.1,
as a `vinospeak` CLI, a `vinospeak-doctor` check and an importable `Synthesizer`.

### 🚀 Features

- Stream speech sentence by sentence, with stoppable playback
- Play speech on the speakers when --output is not given

### 🐛 Bug Fixes

- Fall back to OpenVINO's vocoder pin if the NPU override fails
- Stop synthesizing when the player dies
- Never load OpenVINO's telemetry
- Run Kokoro's vocoder on the NPU instead of the CPU

### 📚 Documentation

- Install from the lock, not from moving HEAD

### 👷 CI/CD

- Publish to PyPI on a version tag

### 🔧 Miscellaneous

- Pin the dev Python to 3.14
- Bring vinoSpeak up to the other vino projects
