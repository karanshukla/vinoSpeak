## [0.1.0] - 2026-10-21

First release on PyPI. Kokoro-82M INT8 on the NPU through OpenVINO GenAI 2026.4.1,
as a `vinospeak` CLI, a `vinospeak-doctor` check and an importable `Synthesizer`.

### 🚀 Features

- Stream speech sentence by sentence, with stoppable playback
- Play speech on the speakers when --output is not given

### 🐛 Bug Fixes

- Fall back to OpenVINO's vocoder pin if the NPU override fails
- Stop synthesizing when the player dies
- Never load OpenVINO's telemetry
- Run Kokoro's vocoder on the NPU instead of the CPU

### 📚 Documentation

- Install from the lock, not from moving HEAD

### 👷 CI/CD

- Publish to PyPI on a version tag

### 🔧 Miscellaneous

- Pin the dev Python to 3.14
- Bring vinoSpeak up to the other vino projects
